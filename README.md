# Modern Chair Product Page 🪑

A sleek, interactive product showcase page for the **Telford Lounge** modern chair, built using pure HTML5 and CSS3 (no JavaScript required). Features dynamic color selection, smooth background transitions, and responsive spec accordions.

🌐 **Live Demo:** [https://newerachair.netlify.app/](https://newerachair.netlify.app/)

---

## ✨ Features

- **Pure CSS Interactivity:** Color variations and tab switching powered entirely by CSS radio input state tricks.
- **Dynamic Color Switcher:** Preview 6 distinct chair colors with synchronized background color accents.
- **Product Details Toggle:** Easily switch between product description and physical dimensions/specs.
- **Responsive Design:** Clean, modern layout crafted to look great on desktop and mobile devices.

---

## 🛠️ Tech Stack

- **HTML5** – Modern semantic markup
- **CSS3** – Custom styling, CSS radio hacks, transitions, and keyframes

## 🚀 Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rohanmuduli/Product-page.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd Product-page
   ```

3. **Open the project:**
   Simply double-click `index.html` or serve it using an extension like VS Code Live Server.
